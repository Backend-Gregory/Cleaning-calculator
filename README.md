# 🧹 Калькулятор уборки — Telegram бот для клининговой компании

Бот рассчитывает стоимость уборки квартиры и собирает заявки.

## 🚀 Функции

- Рассчёт стоимости уборки по площади (200₽/м²)
- Сбор заявки: имя, телефон, адрес
- Отправка заявки владельцу в Telegram

## 🛠 Технологии

- Python 3.11
- aiogram 3.x
- FSM (машина состояний)
- FastAPI + Uvicorn (для деплоя на Render)
